ثمانية منصة صوتية تقدم محتوى عربياً أصيلاً في الأخبار والتحقيقات والبودكاست. تؤمن بأن اللغة العربية قادرة على الوصول إلى كل مكان، وأن القارئ العربي يستحق تجربة قراءة استثنائية. خط ثمانية سيريف تكست صُمّم خصيصاً لهذه الغاية.

Bold 700 — تمييز وعناوين فرعية

الصحافة هي المسودة الأولى للتاريخ. نحن في ثمانية نؤمن بأن القصص تستحق أن تُروى بأجمل الخطوط وأعمق الكلمات وأصدق الروايات.

Light 300 — أجواء هادئة

  href="https://cdn.jsdelivr.net/npm/@engdawood/thmanyah-font-web/index.css">

  href="https://unpkg.com/@engdawood/thmanyah-font-web/index.css">
CSS Usage 
body {
  font-family: "Thmanyah Sans", system-ui, sans-serif;
}

h1 {
  font-family: "Thmanyah Serif Display", serif;
  font-weight: 900;
}

article {
  font-family: "Thmanyah Serif Text", serif;
  font-weight: 400;
}
