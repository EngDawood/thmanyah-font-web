خط ثمانية

حزمة مجتمعية لعائلة خطوط ثمانية — سانس، سيريف ديسبلاي، وسيريف تكست — بخمسة أوزان لكل عائلة. جاهزة للاستخدام على الويب عبر CSS أو CDN أو npm.
الخط من تصميم وملكية ثمانية

GitHub ← npm ←

التثبيت

INSTALL
npm 
npm install @engdawood/thmanyah-font-web
CSS Import 
@import "@engdawood/thmanyah-font-web";
jsDelivr CDN 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@engdawood/thmanyah-font-web/index.css">
unpkg CDN 
<link rel="stylesheet" href="https://unpkg.com/@engdawood/thmanyah-font-web/index.css">
CSS Usage 
body {
  font-family: "Thmanyah Sans", sans-serif;
}
h1 {
  font-family: "Thmanyah Serif Display", serif;
  font-weight: 900;
}
Utility Classes 
<p class="font-thmanyah-sans font-weight-bold">
  نص بخط ثمانية سانس بولد
</p>
